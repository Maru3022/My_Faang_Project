# ADR-002: Hexagonal module boundaries

Status: accepted for foundation.

## Context
The Notion plan requires a modular Kotlin backend that can grow without premature distributed infrastructure.

## Decision
Module root exposes contracts; domain logic must not depend on web or persistence adapters. shared-kernel contains only small domain types.

## Alternatives
Shared JPA entity graph.

## Consequences
Future modules must use public APIs or events; no cross-module repository access.
