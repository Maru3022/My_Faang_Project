# ADR-004: Durable application events

Status: accepted for foundation.

## Context
The Notion plan requires a modular Kotlin backend that can grow without premature distributed infrastructure.

## Decision
Use Spring Modulith JDBC event publication registry, managed by Liquibase. Add domain events with the first business slice.

## Alternatives
Kafka at initial launch.

## Consequences
No external broker yet. Replay and listener idempotency tests required when listeners are added.
