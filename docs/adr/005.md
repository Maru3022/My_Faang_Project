# ADR-005: Stateless HTTP authentication

Status: accepted for foundation.

## Context
The Notion plan requires a modular Kotlin backend that can grow without premature distributed infrastructure.

## Decision
API validates managed-provider JWT signatures, issuer, expiry and audience; sessions and cookie authentication are disabled.

## Alternatives
Build an authorization server or store server sessions in memory.

## Consequences
OIDC provider must be selected before real login. Logout/revocation strategy and short token lifetime must be settled in phase 2; JWT validation alone does not implement immediate revocation.
